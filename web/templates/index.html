    02

    What this is

    यो के हो

    This is a maintainer-built reference project — the kind Nepali developers ship on GitHub and PyPI when they want to show sovereign-AI RAG done carefully: hybrid retrieval, citations to the page, honest eval disclaimers, no vendor lock-in for embeddings.

    It is not Nagarik App, not an official .gov.np product, and not a startup pitch. The code is small on purpose so you can read it, fork it, and wire your own corpus. Built on RAGNav, ragfallback, and AgentEnsemble.

    The demo indexes six PDFs from the public repo Data/ folder (AI Policy, Constitution, DNF, election ordinance, human rights rules, legal maxims). Answers here are retrieved passages only — what you see is what the index returned.

    04

    Use it yourself

    आफै प्रयोग गर्नुहोस्

    $ pip install nepal-gov-agent
    from nepal_gov_agent import GovRAG, download_corpus

corpus = download_corpus("./nepal_gov_data/")
rag = GovRAG(corpus_dir=corpus)

result = rag.ask("नेपालको राष्ट्रिय AI नीतिको उद्देश्य के हो?")
print(result.answer)
for src in result.sources:
    print(src["doc"], "p.", src["page"])
