    § 02

    What this is

    Nepal GovAgent is a worked example of retrieval-augmented generation against a sovereign policy corpus. It uses hybrid lexical and dense retrieval, returns citations down to the page and excerpt level, and runs entirely offline once the documents are indexed. There is no OpenAI key in the loop, no proprietary embedding API, no telemetry.

    The project is published as a reference implementation, not as a product. The code is intentionally small, readable, and clearly attributed to its constituent open-source libraries (RAGNav, ragfallback, AgentEnsemble). A v0.4.0 synthetic evaluation harness ships in the package; the first run surfaces a meaningful gap between English and Nepali retrieval that is documented honestly in the accompanying writeup.

    The demo above runs against a five-PDF seed set: National AI Policy, Constitution of Nepal (2nd amendment, English), Digital Nepal Framework, Human Rights Award Fund rules, and the 2082 election ordinance. The answer text on this page is assembled from retrieved passages with no language-model rewriting in between — what you see is exactly what the retriever returned.

    § 04

    Use it

    pip install nepal-gov-agent
    from nepal_gov_agent import GovRAG, download_corpus

corpus = download_corpus("./nepal_gov_data/")
rag = GovRAG(corpus_dir=corpus)

result = rag.ask("What is Nepal's National AI Policy vision?")
print(result.answer)
for source in result.sources:
    print(f"  {source['doc']} — page {source['page']}")
